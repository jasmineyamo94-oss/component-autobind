# Changelog

All notable changes to this package are documented here.

## [0.2.0] - 2026-07-28

### Changed

- Replaced the generated contracts with `IAutoBindHost` and `IUiViewComponent`.
- Generated bindings now use the nested `UIView` type and private `view` field.
- Removed `IAutoBindTarget` and `IAutoBindComponentSet`.
- Auto Bind and Generate Code report directly to the Unity Console without confirmation dialogs.

### Added

- Optional `com.jasmineyamo.simple-ui-vcontainer` package.
- `ViewLifetimeScope`, `ViewBundle`, concrete `UIView` registration, and Presenter EntryPoint registration.
- A Runtime `ViewManager` with independent HUD, Normal, Top, and System stacks.
- `NonDestroy` caching and configurable `DelayDestroy` lifecycle policies.
- `RegisterSimpleUI()` for consistent VContainer registration.
- Paired VContainer View and Presenter templates under `Create > C# Scripts VContainer View`.
- A modal naming window that previews both script names and creates the two
  template scripts without a Project rename placeholder.
- Version-independent VContainer detection with a Console warning when the optional dependency is missing.
- An importable Resources Demo with Resources-based prefab loading, a runnable
  scene, and PlayMode coverage.

### Upgrade note

- Delete bindings generated by `0.1.0` and generate them again after installing `0.2.0`.
- The unpublished VContainer ViewCore companion was replaced by
  `com.jasmineyamo.simple-ui-vcontainer`; no compatibility aliases are included.

## [0.1.0] - 2026-07-28

### Added

- Core `ComponentAutoBindTool` runtime component.
- `IAutoBindTarget` and `IAutoBindComponentSet` runtime contracts.
- Editor hierarchy scanning, validation, key-map configuration, and deterministic source generation.
- Default UGUI component key mappings without a TextMeshPro dependency.
- Runtime and Editor test assemblies.
- Basic UGUI runtime-created sample.

### Excluded

- VContainer integration.
- Project-specific ViewCore contracts and generated bindings.
- Consumer project settings assets.
